# Sito Longi 1969 — piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sito ufficiale del club Longi 1969 (Seconda Categoria, girone C Sicilia), formato overdrive, con CMS autonomo per la società.

**Architecture:** Astro statico + TypeScript, zero framework runtime. L'impianto (CMS Sveltia, widget Tuttocampo, GDPR, diretta, funzioni OAuth) si **copia e adatta** dal progetto collaudato `C:\Users\tigno\Desktop\città di galati` (d'ora in poi `GALATI`). L'identità visiva e i tre momenti overdrive sono nuovi e scritti da zero.

**Tech Stack:** Astro ^7.1.3, Vitest, Fontsource (Alfa Slab One + Archivo), Sveltia CMS, Netlify (account separato), Higgsfield MCP (Seedance 2.0) per l'hero, ffmpeg per i frame.

## Global Constraints

- Node >= 22.12; `NODE_VERSION=22` su Netlify.
- Palette SOLO da stemma, OKLCH: rosso `oklch(0.55 0.21 27)`, blu `oklch(0.32 0.12 265)`, oro `oklch(0.82 0.15 92)`; mai `#000`/`#fff` puri.
- Font SOLO Alfa Slab One (display) e Archivo (testo), self-hosted Fontsource.
- Animazioni scroll: SOLO proprietà `animation-*` estese (il minificatore fonde la scorciatoia con `animation-timeline` e il browser scarta tutto — bug reale documentato in `GALATI/src/styles/atmosphere.css`).
- Tutto dietro `prefers-reduced-motion`; ripiego IntersectionObserver dove manca `animation-timeline: view()`.
- Testi in italiano, niente trattini lunghi (em dash), niente sezioni "in costruzione": segnaposto onesti o assenza.
- Repo GitHub **pubblico** (Netlify free blocca i build dei privati con contributori CMS non verificati).
- Prima di OGNI generazione Higgsfield: dichiarare il costo stimato e attendere conferma dell'utente.
- Commit frequenti; ogni task termina con build (`npm run build`) e test (`npm test`) verdi.

### Task 3: Spaccatura rossoblù (momento overdrive n.2)

**Files:**
- Create: `src/components/Spaccatura.astro`

**Interfaces:**
- Produces: componente `<Spaccatura />` da piazzare tra due sezioni; prop opzionale `inverti` (bool) per alternare rosso→blu / blu→rosso.

- [ ] **Step 1: componente completo**

```astro
---
// Divisore a taglio diagonale: le due meta' (rossa e blu) si chiudono come
// lo scudo del club mentre il divisore attraversa lo schermo, legate allo
// scroll. Senza animation-timeline o con reduced-motion: taglio statico.
interface Props { inverti?: boolean }
const { inverti = false } = Astro.props;
---
<div class:list={["spaccatura", { inverti }]} aria-hidden="true">
  <span class="meta rossa"></span>
  <span class="meta blu"></span>
</div>
<style>
  .spaccatura {
    position: relative;
    height: clamp(4rem, 12vw, 9rem);
    overflow: hidden;
  }
  .meta { position: absolute; inset: 0; }
  .rossa { background: var(--rosso); clip-path: polygon(0 0, 55% 0, 45% 100%, 0 100%); }
  .blu { background: var(--blu); clip-path: polygon(55% 0, 100% 0, 100% 100%, 45% 100%); }
  .inverti .rossa { background: var(--blu); }
  .inverti .blu { background: var(--rosso); }
  /* SOLO proprieta' animation-* estese: vedi Global Constraints. */
  @supports (animation-timeline: view()) {
    @media (prefers-reduced-motion: no-preference) {
      .rossa {
        animation-name: chiusura-sx; animation-duration: 1s;
        animation-fill-mode: both; animation-timing-function: var(--ease-out-quart);
        animation-timeline: view(); animation-range: cover 0% cover 100%;
      }
      .blu {
        animation-name: chiusura-dx; animation-duration: 1s;
        animation-fill-mode: both; animation-timing-function: var(--ease-out-quart);
        animation-timeline: view(); animation-range: cover 0% cover 100%;
      }
    }
  }
  @keyframes chiusura-sx {
    from { transform: translateX(-46%); }
    to { transform: translateX(0); }
  }
  @keyframes chiusura-dx {
    from { transform: translateX(46%); }
    to { transform: translateX(0); }
  }
</style>
```
